# Arcana Kin

Arcana Kin is an open-source multilingual 3D tarot reading web app built with React, TypeScript, Vite, and Three.js.

## Features

- Traditional Chinese, English, and Japanese UI copy
- A full 78-card tarot data model
- Multiple spreads and reading lenses
- Interactive Three.js table with animated shuffling, dealing, hover states, and card flips
- Procedural card textures rendered to canvas for easy open-source customization

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
